# Camera Man

A Babric mod for BTA that allows you to use freecam!  
**Note:** Freecam only works if both the client and server have the mod installed.

## Dependencies

- [Halplibe 5.2.4](https://github.com/Turnip-Labs/halplibe)
- [Raywire 1.0.2](https://github.com/Apollointhehouse/raywire)
- [Fabric Language Kotlin 1.13.3](https://github.com/FabricMC/fabric-language-kotlin)

## Usage

- Place the mod and its dependencies into the mods folder for both the server and the client.
